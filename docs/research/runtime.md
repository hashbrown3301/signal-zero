# Runtime audit and primary-source research

1 October 2026; `Upgradation`; inspected current code and existing cloud results before feature implementation. No physical-phone, Firebase, emulator or new native benchmarks were run for this audit.

## Findings that affect the plan

- **Good existing foundations:** `OfflineTranslator` serializes inference with a mutex and bounded exact-input LRU; `NllbRuntime` owns/cleans encoder, decoder and cached key/value results, uses exact native SentencePiece, fixes target-language tags, and explicitly fails at source/output limits rather than truncating. Pack/derived-model activation verifies pinned SHA-256 and writes atomically. Preserve these behaviors.
- **A transcript error currently becomes a spoken translation without review.** `SessionManager.handleSpeech` immediately sends/enqueues ASR output; playback prepares and speaks the model output. Add optional source edit/confirm/discard before submission, keeping the existing fast path available.
- **Digits matching is not translation accuracy.** The current benchmark report records Hindi Rohan→“Rohn”, destination omissions and a potentially changed Odia 25-not-50 condition, despite passing digit-bag checks. Compare numeric *multisets* with Unicode decimal digits, signs, decimal/grouping punctuation, percentage markers and grouped time components. Flag missing/changed/added values before automatic speech. Do not give an unflagged result a correctness/confidence label: this check cannot detect swapped roles, negation, names, units or spelled-out quantities.
- **Native cancellation is cooperative between calls.** `ensureActive` checks do not stop an in-flight ORT run, session loading or file hashing. ORT Java 1.27 exposes `RunOptions.setTerminate` as a future cancellation/deadline improvement, documented as terminating “as soon as possible”; it does not promise immediate cancellation. The current output-token limit is a correctness bound, not a time deadline.
- **The model remains expensive even after optimization.** Existing measured peak is about 1.9 GiB in a cloud JVM; the original pack plus derived decoder occupies about 1.4 GB. Native sessions persist until ViewModel teardown; decoder reuse also rehashes roughly 475 MB on reopening. Safely release idle sessions, avoid cache-hit latency being reported as inference, and perform exact reviewed-phrase lookup before runtime loading and the memory guard. A miss still requires the ordinary model/hardware: do not advertise arbitrary low-RAM translation.
- **Backpressure and recovery need session-level work.** Playback currently has an unlimited channel and in-flight duplicate tracking, while visible history is bounded. Review pauses can worsen the backlog. Bound accepted work without blocking network keepalives; preserve receipt versus actual-audio semantics. Add typed input, retry from preserved source and replay from preserved output; reuse cancellation/dedup/voice-error paths.

Relevant code: `translation/OfflineTranslator.kt`, `translation/NllbRuntime.kt`, `translation/RuntimeModelPatch.kt`, `session/SessionManager.kt`, `app/MainViewModel.kt`; current semantic examples are in `docs/CURRENT_APP_BENCHMARKS.md`.

## Recommended four-feature implementation and tests

1. **Review/correct recognized source:** no translation or network send until confirmation in review mode; discard/close/cancel sends nothing; corrected text joins the normal bounded pipeline.
2. **Critical-detail review gate:** pure checker returns warning strings, never a score. Tests cover Indic/Arabic/astral decimal digits, repeated quantities, minus/+ signs, decimal/grouping ambiguity, percentages, reordered time components, missing/added values and known undetectable role reversals. Session tests prove flagged output is visible but synthesis requires explicit review/Play anyway.
3. **Exact user-reviewed phrasebook:** directed language keys; preserve scripts, case, numbers and signs; normalize only agreed whitespace. Lookup precedes model loading and caches. Save requires explicit editable source/target review; provenance says user-reviewed, not certified. Tests prove a hit works with a failing/unavailable model, a miss falls through, language isolation, persistence/corruption bounds and edits/deletions take effect.
4. **Typed/retry/replay recovery:** type through the same input checks; retry preserves source; replay uses retained output without another model call. Preserve warning consent, voice failures and duplicate handling. Test repeated presses, stale work after close, review backpressure, missing voice then retry, and translation failure then retry.

The five honest product differentiators are the combination of ten-language local hold-to-talk, local peer text transport, user-controlled source/detail review, exact reviewed phrases without native translation, and recoverable/measurable conversation. They are not claims of worldwide novelty. Keep existing model/runtime intact during this feature iteration. Compare future alternatives on pinned human-reference data (directional chrF++ plus bilingual critical-error review), runtime/memory/storage and licensing before considering replacement. Label every current performance result as cloud-only; hardware/audio/link/battery/thermal qualification remains separate.
